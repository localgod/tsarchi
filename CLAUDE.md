# tsarchi

TypeScript library that loads, edits, validates and saves Archi (`.archimate`) models. The goal is lossless load → save of files produced by Archi itself.

## Commands

- `npm test` — builds (`pretest`), then runs vitest. Tests import from `src`, but `prebuild` regenerates `src/index.mts`.
- `npm run lint` / `npm run format` — oxlint and oxfmt (format only checks README, LICENSE, CHANGELOG).
- `npm run roundtrip:diff -- [file|dir ...]` — load → serialize → diff without validation, grouped by what was lost. Defaults to all fixtures. Use it before and after any parse/serialize change (see the `archi-roundtrip-diff` skill).
- `npm run compare` — strict round-trip of `tests/fixtures/roundtrip` (same check as `RoundtripFixtures.test.mts`).

## Layout

- `src/Archimate.mts` — public model API; `parse()` / `serialize()` / `validateModel()`.
- `src/internal/Parser.mts`, `src/internal/Serializer.mts` — schema (XML-shaped) ⇄ domain model.
- `src/internal/DiagramAttributeMapper.mts` — attribute tables (`childAttributes`, `connectionAttributes`, `childTextElements`) that drive both parse and serialize of diagram children and connections.
- `src/internal/SourceConnectionMapper.mts`, `src/internal/BoundMapper.mts` — view connections and bounds.
- `src/constants/archimate-mappings.mts` — element/view types, folders, `toXsiType()` / `typeFromXsiType()`.
- `src/interfaces/` — domain types; `src/interfaces/schema/` — fast-xml-parser shapes (`@_` attribute keys, all values strings).
- `src/index.mts` — generated by `scripts/generate-index.js`; do not edit, and note every `src/**/*.mts` file becomes public API, except `src/internal/`, `src/node/` and `src/interfaces/schema/`. Put helpers that are not meant for users in `src/internal/`.
- `src/node/` — code that uses Node built-ins (`TsArchi`), exported from `tsarchi/node` via the hand-written `src/node/index.mts`. The main index must stay browser-safe; `tests/BrowserBundle.test.mts` bundles it for the browser and fails on any Node built-in.

## Conventions and gotchas

- Imports use the `.mjs` extension for `.mts` sources.
- fast-xml-parser returns a single object for one child element and an array for several. Every repeatable element (`child`, `sourceConnection`, `property`, `feature`, `bendpoint`, `folder`, `element`) must be typed `T | T[]` in the schema and normalized when read.
- Domain `type` values carry no namespace prefix. Always go through `typeFromXsiType()` when reading and `toXsiType()` when writing; never add or strip `archimate:` by hand. Canvas types use `canvas:`.
- Only write an attribute or element on save when it was present on load (or set in code), so files round-trip byte-for-byte after normalization.
- Newer Archi styling (e.g. `lineAlpha`, `gradient`, `iconColor`, `iconVisible`) is stored as `<feature name="…" value="…"/>`, not as attributes. Check the real format before mapping anything (see the `verify-archi-format` skill).
- `*.archimate` is gitignored: new fixtures need `git add -f`.

## Fixtures

- `tests/fixtures/archi/` — unmodified files from the Archi repo, provenance listed in its `README.md`. They may still fail validation or round-trip; `tests/ArchiFixtures.test.mts` covers them.
- `tests/fixtures/roundtrip/` — hand-written fixtures that must validate and round-trip exactly. Every file here is picked up automatically.

## Changes

- Add an entry under `## [Unreleased]` in `CHANGELOG.md` (Added / Changed / Fixed), linking the issue.
- PR body sections: Problem, Changes, Tests, Out of scope (with follow-up issues filed for anything left).
- Skills in `.claude/skills/`: `fix-archi-issue` (end-to-end workflow), `add-archi-attribute`, `verify-archi-format`, `archi-roundtrip-diff`.
